# Licence of this directory

`libaltc264.c` is a decoder wrapper for FFmpeg's libavcodec, and `apply.sh`
adds it to an FFmpeg source tree. Once applied it is part of FFmpeg, so
`libaltc264.c` is licensed, like FFmpeg, under the GNU Lesser General Public
License, version 2.1 or later (see its header).

The rest of this repository, including the altc264 library that the wrapper
links against, is under the MIT licence in the top-level `LICENSE`.
